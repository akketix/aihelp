# Security Policy

## Reporting a Vulnerability
If you discover a security vulnerability in the AI Help Wiki, please report it responsibly — **do not open a public GitHub issue**.
- Email: **security@mneurix.dev**
- We aim to acknowledge within 2 business days and will coordinate a fix + disclosure timeline with you.

## Scope
This policy covers the `aihelp` wiki — source: https://github.com/akketix/aihelp · site: https://aihelp.mneurix.dev

## Out of Scope
- Vulnerabilities in third-party platforms (Astro, Starlight, DigitalOcean, Cloudflare) — report to the respective vendor.
- Issues requiring physical access, social engineering, or denial-of-service via volume.

English.
